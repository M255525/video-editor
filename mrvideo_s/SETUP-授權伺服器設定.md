# 授權伺服器設定指南（課程講師專用，僅需設定一次）

這份工具（影片先生·課程教學版）在頁面一開啟就會顯示「課程授權序號」的鎖定畫面，**必須輸入序號並按「確認」驗證通過，才能使用整個工具**（不是只鎖某個功能）。序號需連到你的 Google Sheet 確認是否還在 12 個月使用期限內。這個檢查是透過 **Google Apps Script**（Google Sheet 內建、免費）架設的一支小型 API 完成的，需要你手動部署一次。部署完成後，往後每次要開放給新的班級，只要在 Google Sheet 新增一列即可，不需要重新部署。

## 你的 Google Sheet

<https://docs.google.com/spreadsheets/d/1hVluEpy_0RgVUXGWj72o01mGplPQVqNRiNGJCstBREY/edit>

表格需要有這些表頭欄位（表頭文字要完全一致，程式是用表頭文字比對欄位，不是用欄位順序，這樣你之後自己在表格加減其他欄位不會弄壞驗證邏輯）：

| 序號 | 開始日期 | 結束日期 |
|---|---|---|

程式只會讀寫這三欄，其餘欄位（如果表格裡還有其他你自己在用的欄位，例如任務追蹤用的「優先順序」「負責人」「狀態」等）不會被動到。

## 部署步驟

1. 開啟上面的 Google Sheet。
2. 點選選單「**擴充功能（Extensions）→ Apps Script**」，會開啟一個新分頁的程式碼編輯器。
3. 把編輯器裡預設的 `function myFunction() {}` 全部刪除，貼上本資料夾 `Code.gs` 的完整內容，然後按左上角儲存（磁片圖示）。
4. 點右上角藍色「**部署（Deploy）→ 新增部署作業（New deployment）**」。
5. 左邊齒輪圖示選「**網頁應用程式（Web app）**」。
6. 設定：
   - 說明：可填「影片先生課程教學版 授權檢查」
   - 執行身分（Execute as）：**我（你的帳號）**
   - 誰可以存取（Who has access）：**任何人（Anyone）** ← 這一步一定要選「任何人」，否則學員的瀏覽器連不到
7. 點「部署」。第一次部署會跳出 Google 的授權確認畫面（因為腳本要讀寫你的 Sheet）：
   - 選你的帳號 → 若出現「Google 尚未驗證這個應用程式」，點左下角「進階」→「前往 (不安全)」→ 允許。這是正常現象（因為這是你自己寫的私人腳本，沒有送 Google 審查），不是真的有安全疑慮。
8. 部署完成後會顯示一組網址，格式類似：
   ```
   https://script.google.com/macros/s/AKfycb.................../exec
   ```
   複製這組網址。

## 把網址接上工具

打開 `mrvideo_s/js/license-gate.js`，搜尋 `LICENSE_CHECK_URL`，把空字串改成剛剛複製的網址：

```js
var LICENSE_CHECK_URL = "https://script.google.com/macros/s/AKfycb.................../exec";
```

存檔即可。如果之後要重新打包桌面版執行檔，記得改完前端檔案要重建。

## 驗證部署是否成功

部署完成的網址直接貼到瀏覽器網址列開啟（GET 請求），應該會看到：

```json
{"ok":true,"message":"授權伺服器運作中。請用 POST 傳送 JSON body，例如 {\"serial\":\"your-serial-here\"}"}
```

看到這個就代表部署成功。**注意：不要用 `curl` 測試實際的驗證（POST 請求）**，Apps Script 的轉址機制會讓 curl 出現誤導性錯誤（不代表真的壞了）；請直接在瀏覽器打開 `mrvideo_s/index.html` 測試，填入 Sheet 裡的一組序號並按「確認」，確認鎖定畫面消失、頁尾顯示「🔑 剩餘 N 天可用」。

## 之後每次要開放給新的班級要做什麼

**不需要重新部署 Apps Script。** 只要：

1. 打開 Google Sheet，新增一列。
2. 「序號」欄填一組你要發出去的序號（例如產生一組隨機英數字串）。
3. 「開始日期」「結束日期」兩欄**留空**——第一次有學員驗證這組序號時，系統會自動把「開始日期」寫成當下時間，「結束日期」自動算成開始日期 + 12 個月。
4. 把這組序號發給該班級。

如果想手動指定某組序號的起訖日期（例如想讓有效期從某個特定日期算起，而不是從第一次使用算起），也可以直接在 Sheet 手動填「開始日期」「結束日期」，系統偵測到已有值就不會覆蓋，直接以你填的日期為準。

## 修改使用期限長度

在 `Code.gs` 開頭的 `const VALID_AMOUNT = 12;` 改掉這個數字，改完要回到 Apps Script 編輯器貼上新版程式碼，再「部署 → 管理部署作業 → 編輯 → 部署」一次（**部署網址不會變**，不需要再改前端檔案）。

## 關於「鎖住整個工具」與其他教學版（sbir-gen-s／icap_s）的差異

其他幾個課程教學版（sbir-gen-s、icap_s）是只鎖「AI 優化」單一功能，其餘功能永久可用；**影片先生課程教學版是鎖整個工具**——頁面一開啟就顯示全螢幕鎖定畫面，序號驗證通過才會顯示編輯器。這是應你的要求做的設計，`js/license-gate.js` 與其他教學版的 `licenseSerial` banner 各自獨立運作、不共用程式碼。

另外，為了避免「驗證通過後就永久放行、序號到期也不會被擋下」的問題，工具在背景每 20 分鐘會靜默重新驗證一次序號；如果序號在使用期間到期，畫面會自動重新鎖定。

## 常見問題

- **學員按確認一直顯示「無法連線授權伺服器」**：先檢查 `LICENSE_CHECK_URL` 是否已經填好網址（不是空字串）；再檢查步驟 6 的存取權限是否真的選了「任何人」。
- **改了 Code.gs 之後網址失效或行為沒變**：Apps Script 修改程式碼後，必須到「部署 → 管理部署作業 → 編輯（鉛筆圖示）→ 版本選「新版本」→ 部署」才會生效，只存檔不會自動更新已部署的網址。
- **想收回某組序號的使用權**：把該列的「結束日期」改成一個過去的日期即可，之後驗證都會回傳逾期，畫面會在最多 20 分鐘內自動重新鎖定。
