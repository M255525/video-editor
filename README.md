## 快速開始

1. **開啟**：用 **Chrome 或 Edge** 瀏覽器開啟 `index.html`（直接雙擊檔案即可）。
2. **匯入**：把影片檔拖進左側「媒體」面板的虛線框。
3. **上軌**：把素材縮圖拖到下方時間軸的「主影片軌」（或按縮圖上的 ＋）。
4. **剪輯**：拖動片段調位置、拖邊緣裁長度、按 `S` 在播放頭處分割。
5. **預覽**：按 `空白鍵` 播放。
6. **匯出**：按右上角「⬆ 匯出影片」→「開始匯出」，完成後自動下載 MP4。

三分鐘就能完成第一支影片。

## 匯入素材

三種方式：點擊左側虛線框選檔、把檔案拖進虛線框、或直接拖到視窗任何地方。

### 支援格式

| 類型 | 建議格式 | 說明 |
|---|---|---|
| 影片 | **MP4（H.264）** | 首選；手機拍攝、剪映匯出預設格式 |
| | WebM、MOV | Chrome/Edge 可直接播放；MKV 視內部編碼而定 |
| | ~~AVI / WMV~~ | ❌ 瀏覽器無法解碼，請先轉成 MP4 |
| 音訊 | **MP3**、WAV、M4A/AAC、OGG、FLAC | 皆可直接使用 |
| 圖片 | PNG、JPG、GIF、WebP、BMP、SVG | 預設上軌長度 4 秒，可自由拉長 |
| 字幕 | **SRT**、VTT | 自動生成字幕軌（見[文字與字幕](#文字與字幕)） |

### 素材庫操作

- **雙擊**縮圖或按縮圖左上角 **＋**：加到播放頭位置
- **拖曳**縮圖到時間軸：精確放到想要的位置
- 縮圖右下角 **×**：刪除素材（連同時間軸上引用它的片段）

## 時間軸剪輯

| 操作 | 方法 |
|---|---|
| 選取片段 | 點一下片段（藍框＝選取中） |
| 移動位置 | 按住片段左右拖曳 |
| 換軌道 | 按住片段上下拖曳到相容軌道（片段會跟著移動） |
| 裁切長度 | 拖曳片段**左右邊緣** |
| 分割 | 選取片段 → 播放頭移到分割點 → 按「✂ 分割」或 `S` |
| 刪除 | 選取後按「🗑 刪除」或 `Delete` |
| 跳時間 | 點時間刻度尺或軌道空白處 |
| 縮放時間軸 | 右下角「縮放」滑桿 |
| 吸附 | 開啟後拖曳自動對齊其他片段邊緣與播放頭 |
| 上一步/下一步 | 時間軸左上角按鈕，或 `Ctrl+Z` / `Ctrl+Y` |

### 拖放的顏色提示

從素材庫拖素材到時間軸時：

- 🔵 **藍色虛線框**＝可直接放置的落點預覽
- 🟡 **琥珀色**＝此位置與現有片段重疊，放開後會**自動新增一條軌道**疊放（比照剪映）
- 🔴 **紅色**＝軌道類型不相容（例如音訊拖到影片軌）
- 相容的軌道整條會亮起藍光

## 軌道與圖層

- **預設 4 軌**（上→下）：文字/貼圖軌、畫中畫軌、主影片軌、音訊軌
- **圖層規則：清單越上面＝畫面越上層**（上層蓋過下層）
- **調整圖層**：按住左側**軌道名稱**上下拖曳即可改變疊放順序
- **新增軌道**：時間軸工具列「＋軌道」選單（音訊軌／畫中畫軌／文字貼圖軌，數量不限）
- **刪除軌道**：空軌道的標頭會出現 ✕
- **靜音/隱藏**：軌道標頭的 🔊 按鈕（影片軌按下＝整軌隱藏；音訊軌＝整軌靜音）
- 文字與貼圖除了放疊加軌，也可以**直接拖到影片軌**

## 文字與字幕

### 手動加文字

「文字」面板 → 點**標題／字幕／標語（含底色）**其中一種 → 文字加到播放頭位置 → 右側面板編輯：

- 內容（支援多行）、字體（正黑/標楷/明體/Impact 等）、字級、粗體
- 文字顏色、描邊顏色與寬度、底色開關
- 位置/大小直接在預覽畫面拖曳調整

### 匯入 SRT 字幕檔

「文字」面板 →「📄 匯入 SRT / VTT 字幕檔」（或直接把 .srt 拖進匯入區）：

- 自動建立專用的「字幕」軌（置頂）
- 每句字幕依時間碼精確生成，自動套用字幕樣式（白字黑邊、靠下方）
- 匯入後每句都是獨立文字片段，可個別修改文字、樣式、時間

### 🤖 語音轉字幕（自動辨識講話內容）

影片/音訊裡如果有人講話，但時間軸上還沒有任何文字片段，可以用這個功能自動生成字幕，不用自己聽打：

- 先到左側「**⚙️設定**」分頁填入自備的 **Gemini API 金鑰**（只存在本機瀏覽器；到 [Google AI Studio](https://aistudio.google.com/apikey) 免費申請）
- 再到「文字」面板按「🤖 辨識全片講話並生成字幕」
- 會把時間軸上目前所有有聲音的片段混音、編碼成 mp3，送到 Gemini 辨識並要求標出每句時間戳記，依偵測到的時間點自動生成文字片段，放進「字幕」軌（與匯入 SRT 是同一條軌）
- 辨識完成後每句字幕都是獨立文字片段，可再手動修改文字、時間、樣式
- 依片長需要數十秒到數分鐘不等；混音後音訊超過 15MB 會顯示錯誤，請縮短時間軸長度
- 這個功能會把混音後的音訊上傳給 Google Gemini 處理，跟其他工具的「自備 API 金鑰」功能一樣，金鑰只存在你的瀏覽器
- **時間戳記為 Gemini 自行估算**，精確度不如專門的語音辨識服務，建議生成後手動核對每句字幕的時間點
- 長句子會自動依安全區域斷行，不會超出畫面左右邊緣

## 濾鏡與調色

**先選取影片或圖片片段**，再到「濾鏡」面板點選：

| 濾鏡 | 效果 |
|---|---|
| 原圖 | 移除所有濾鏡 |
| 鮮明 | 提高飽和度與對比 |
| 暖陽 / 冷調 | 色溫偏暖 / 偏冷 |
| 復古 / 膠片 | 低飽和懷舊感 / 高對比電影感 |
| 黑白 | 去色 |
| 夢幻 | 柔光微模糊 |
| 畫面模糊 | 整個畫面模糊化（背景虛化、隱私遮蔽） |

套用後可在右側「濾鏡調整」用滑桿微調：**亮度、對比、飽和、色相、模糊**，「重設濾鏡」一鍵歸零。

## 轉場

轉場掛在片段的**開頭**，與前一個緊鄰片段銜接：

1. 選取後面那個片段
2. 「轉場」面板點選：**交疊淡化**（兩畫面交融）、**黑場過渡**、**擦除**、**滑動**
3. 右側面板可調轉場時長（0.1–5 秒）

片段左緣會出現 ⇄ 標記代表已套用轉場。

---

## 變速

選取影片或音訊片段 → 右側「變速」區：

- **速度**：0.1×（慢動作）～ 8×（快轉），片段長度自動跟著改變
- **曲線**（影片限定）：等速／蒙太奇（慢→快）／子彈時間（快→慢）／英雄時刻（中間慢）／兩端慢

> 變速會改變音調（越快音越高）。曲線變速以動態播放速率近似，分割帶曲線的片段會重設為等速。

---

## 關鍵影格動畫

讓元素的**位置、縮放、旋轉、不透明度**隨時間變化（適用影片/圖片/文字/貼圖）：

1. 選取片段，播放頭移到動畫**起點** → 右側「變換與關鍵影格」按該屬性的 **◆**
2. 播放頭移到**終點** → 修改屬性值（或直接在預覽畫面拖曳/滾輪縮放）→ 再按一次 ◆
3. 播放時數值會在兩個關鍵影格之間平滑過渡

- 片段下緣的**白色菱形**＝關鍵影格位置
- ◆ 亮藍色＝播放頭正好在關鍵影格上（再按一次可移除）
- ✕＝清除該屬性全部關鍵影格
- 範例：開場標題「從小到大浮現」＝ scale 在 0 秒設 50%、1 秒設 100%，opacity 同步 0% → 100%

## 音訊調整

選取影片或音訊片段 → 右側「音訊」區：

- **音量**：0–200%
- **靜音**：單一片段靜音
- **淡入/淡出**：秒數設定，背景音樂開頭結尾平滑進出

多條音訊軌可以同時疊放（背景音樂＋旁白＋音效），混音自動處理。

## 匯出影片

按右上角「⬆ 匯出影片」→「開始匯出」。

### 🎬 完整預覽

正式匯出前，可以先按頂部工具列「🎬 完整預覽」看看最終合成結果：畫面會切換成放大的「劇院模式」（隱藏左右面板與時間軸），從頭開始播放整段影片，跟編輯時中央畫布的即時預覽是同一套合成引擎，能完整呈現濾鏡、轉場、文字、貼圖與音訊混音的效果。按右上角「✕ 結束完整預覽」或鍵盤 `Esc` 可隨時退出，回到一般編輯畫面。

### ⚡ 快速匯出（預設）

- **背景編碼，無需播放影片**，速度快（通常比影片長度快數倍）
- 輸出標準 **MP4（H.264＋AAC）**，任何裝置可播
- 顯示進度百分比與預估剩餘時間，可隨時取消
- 完成後自動下載，檔名＝專案名稱＋日期

### 即時錄製（自動備援）

若瀏覽器不支援快速匯出（或離線無法載入封裝元件），會自動改用即時錄製：從頭播放一次並同步錄下（耗時＝影片長度），過程請勿切換分頁。

### 附加匯出：字幕 .srt／音軌 .mp3

匯出對話框裡有兩個選用勾選框，會在影片下載完成後**額外多下載**對應的檔案：

- **同時匯出字幕檔（.srt）**：把時間軸上所有文字片段（含手動打的、匯入的、或語音辨識生成的）依時間排序輸出成標準 SRT 字幕檔。時間軸上沒有任何文字片段時會提示略過。
- **同時匯出音軌（.mp3）**：把目前所有音軌（含影片本身的聲音）混音後輸出成獨立的 .mp3 檔案，方便另外剪輯或上傳。時間軸上沒有可用音軌時會提示略過。

## 專案儲存與還原

- **自動存檔**：每次編輯後自動儲存到瀏覽器（頂部顯示「已自動儲存」），`Ctrl+S` 可手動存
- **素材也會保存**：匯入的檔案存在瀏覽器的本機資料庫，關掉重開仍在
- **素材離線**：若瀏覽器清除了資料，片段會顯示「素材離線」——重新匯入**同名檔案**即自動接回，剪輯內容不會遺失
- **新專案**：時間軸與素材庫**全部清空**，從零開始（會先跳出確認對話框）
- 注意：專案存在**這台電腦的這個瀏覽器**裡，換電腦或無痕模式看不到

## 常見問題

**Q：拖第二個音訊（或影片）進去，位置重疊怎麼辦？**
A：直接放！系統會自動新增一條軌道疊放（拖曳時顯示琥珀色預覽就代表會這樣處理）。

**Q：影片拖不進去 / 匯入失敗？**
A：多半是格式問題。AVI、WMV 瀏覽器無法解碼，請先用其他工具轉成 MP4（H.264）。

**Q：匯出的影片別人打不開？**
A：快速匯出產生的是標準 MP4，各平台通用。若當時是「即時錄製」模式且輸出 .webm，可改用 Chrome/Edge 重新匯出 MP4。

**Q：為什麼建議用 Chrome / Edge？**
A：快速匯出、部分格式解碼依賴這兩款瀏覽器的能力；Firefox 基本可用但匯出較慢，Safari 不建議。

**Q：我的素材會被上傳到網路嗎？**
A：不會。整個編輯器都在你的瀏覽器本機執行，素材與專案只存在你的電腦裡。

**Q：畫面卡頓？**
A：素材建議 1080p 以內；同時疊放的影片軌控制在 2–3 軌；時間軸縮放調小一點也有幫助。
